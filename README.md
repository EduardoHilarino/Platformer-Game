# 🎮 2D Platformer

*A 2D precision platformer inspired by Celeste, focused on challenging movement, exploration, and problem-solving.*

## 📖 About the Game

The goal is simple: **reach the end of each level!** But don't expect it to be easy.

This game is a 2D precision platformer where players must overcome challenging obstacles using movement skills, timing, and logic.

Rather than focusing only on jumping between platforms, the game encourages players to experiment with different approaches and find creative solutions.

The project is still in development, with a strong focus on responsive controls, satisfying animations, and polished pixel-art visuals.

## 🕹️ Controls

| Key | Action |
|---|---|
| **A / D** | Move left / right |
| **Space** | Jump |
| **Hold Space** | Jump higher |
| **Shift** | Dash |
| **W / A / S / D + Shift** | Directional Dash |
| **C** | Grab walls |
| **C + W** | Climb up |
| **C + S** | Climb down |
| **Space near a wall** | Wall Jump |
| **F3** | Toggle Debug HUD |

**Dash can be performed both on the ground and in the air!**

The movement system also supports advanced techniques, including Super Jumps, allowing players to combine mechanics and overcome obstacles in creative ways.

## ⚡ Movement Mechanics

The game features a custom movement controller inspired by Celeste's responsive gameplay.

### Basic Movement

- **Acceleration & Deceleration:** Smooth movement with controlled momentum.
- **Variable Jump Height:** Hold the jump button to jump higher.
- **Coyote Time:** Jump briefly after leaving a platform.
- **Jump Buffering:** Press jump shortly before landing to jump immediately.
- **Air Control:** Adjust your movement while airborne.

### Advanced Movement

- **8-Directional Dash:** Dash horizontally, vertically, or diagonally, both on the ground and in the air.
- **Super Jump:** Perform advanced jumps by combining movement mechanics.
- **Wall Jump:** Push yourself away from walls.
- **Wall Slide:** Slide down walls with reduced falling speed.
- **Wall Grab:** Hold onto walls using the grab button.
- **Wall Climbing:** Climb up or down walls with stamina management.

Mastering these mechanics is an important part of overcoming the game's more difficult challenges.

## 🎨 Visuals & Animations

All pixel-art sprites, character animations, and level artwork are created in GameMaker.

The game includes:

- Custom running, jumping, falling, turning, dashing, and climbing animations.
- **Squash & Stretch** effects for expressive movement.
- Pixel-art smoke effects for jumping and landing.
- Directional dust particles for Wall Jumps and Wall Slides.
- Running and braking dust particles.
- Dash trails and movement effects.
- Tile-based environments with randomized visual variations.

The visual effects are designed to improve movement feedback without interfering with gameplay precision.

## 🛠️ Debug HUD

Press **F3** to show or hide the built-in Debug HUD.

It displays information such as:

- Current movement state.
- Horizontal and vertical velocity.
- Grounded status.
- Available dashes.
- Jump Buffer and Coyote Time.
- Climbing stamina.

This feature helps with testing and improving the movement system.
